# ISO 20816-3 Severity (`ISO.Severity:iso20816`)

Standards-anchored vibration-severity gauge. Consumes a vibration `signal`
tensor and emits the broadband **velocity RMS (mm/s)** over the ISO **10-1000 Hz**
band, classified into zone **A / B / C / D** for the configured machine group and
support type. A learned severity score can run beside it; the ISO zone is an
auditable, standards-backed corroboration channel.

## Inputs / outputs

- **signal** (tensor, required): a 1-D vibration window that carries a **unit
  tag** (`tensor.unit`) with `quantity` = `Acceleration` (g / m/s²) or `Speed`
  (m/s / mm/s) and `sampleRateHz`. If the signal is acceleration it is integrated
  to velocity in the frequency domain (`V(f)=A(f)/(j·2πf)`).
- **assessment** (any): the full verdict (`assessed` or `refused`).
- **rms_mm_s** (float): broadband velocity RMS in mm/s, or `-1` when refused.
- **zone** (float): `A=0, B=1, C=2, D=3`, refused `-1`.

## Editables

- **machine_group**: `1` (large, > 300 kW) or `2` (medium, 15-300 kW).
- **flexible_support**: `false` = rigid, `true` = flexible.
- **operating_rpm**: `0` = unknown; below 600 rpm the band's lower edge drops to 2 Hz.
- **power_kw**: `0` = unknown; below 15 kW the node **refuses** (out of ISO scope).

## Refuse, never guess

The node returns `status: "refused"` (with a `reason` + `remedy`, and `zone = -1`)
rather than emit a misleading verdict when: the signal has **no unit tag**, the
quantity is not Acceleration/Speed, the unit key is unknown, the **sample rate is
too low** to cover 10-1000 Hz (needs ≈ ≥ 2106 Hz), the machine is **below 15 kW**,
or the window is too short. The unit is **never inferred from amplitude**.

## Thresholds

ISO 10816-3:2009 four-zone velocity-RMS table (mm/s), by machine group + support:

| group / support | A\|B | B\|C | C\|D |
|---|---|---|---|
| 1 rigid | 2.3 | 4.5 | 7.1 |
| 1 flexible | 3.5 | 7.1 | 11.0 |
| 2 rigid | 1.4 | 2.8 | 4.5 |
| 2 flexible | 2.3 | 4.5 | 7.1 |

A boundary value belongs to the **lower** zone (`≤`). ISO 20816-3:2022 supersedes
10816-3 and merges zones A and B; A/B are kept for practitioner familiarity.

Every graded verdict carries a structured **`provenance`** (`IProvenance`): which
standard, edition, and threshold table produced the zone
(`{ kind:"standard", source:"ISO 20816-3", version:"2022 (supersedes ISO 10816-3:2009)",
basis:"machine group 2, rigid support", note:"..." }`). See
`docs/architecture/provenance-convention.md`.
