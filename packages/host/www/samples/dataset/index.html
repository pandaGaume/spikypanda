Labeled Dataset Capture

Subscribe to any stream published on the SharedWorker registry, label its windows, record N of them, download as CSV or JSON.

What this page does

This page is a generic dataset recorder. It does not generate data; it consumes whatever stream a producer page is publishing. Open the Motor current source in another tab and hit Start there, then come back here and pick the stream from the dropdown.

Each window is sliced from the stream at the producer's sample rate and tagged with the user-supplied label plus the stream's metadata (motor config, fault config, ...) so the dataset is reproducible and self-describing.
