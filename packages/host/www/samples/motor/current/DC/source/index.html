Motor Current Source

Configure a DC motor + faults, preview the live current and spectrum, publish the signal as a stream that other pages (capture, live test) can subscribe to.

What this page does

Configure a DC motor on the right (preset or custom), stack zero or more faults, watch the resulting current signal and its spectrum live on the left. The motor physics, fault signatures and noise are computed locally with the @spiky-panda/sensors package, the same code that compiles to C++ for the MCU.

Hit Start in the Stream panel to publish the signal as a labeled stream. Other browser tabs (the labeled-capture page, a live-test page, etc.) can subscribe to it via the shared registry. Pause stops publishing without dropping the registration; Stop unregisters the stream entirely.
