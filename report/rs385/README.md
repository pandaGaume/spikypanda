## Result in one line

Tilting the shaft reproduces the effect of removing gravity, exactly and
following `cos(tilt)`. A ground campaign sweeping 0 to 90 degrees therefore
produces the microgravity end of the training distribution on a bench, which
keeps a multichannel fault classifier usable in orbit. What the same fact
forbids is the inverse: the current alone cannot say whether a signature
vanished because of attitude or because of gravity. One static accelerometer
channel settles that, and the montage already carries it.

## The graph

35 nodes, 38 connections: scene, placement (Attitude then Transform), drive
slider, motor, turbine payload carrying two faults, speed feedback, housing,
IMU, current sensor, six line plots and four FFT chains, with a dashboard
layout.

The orientation knob is the `pitch` field of the Attitude node. It feeds one
world matrix into the `parentWorld` of the motor, the turbine and the housing,
so tilting the assembly tilts every body that projects gravity.

**Status: verified running in the editor and headless, with matching numbers.**
Loading the graph and sweeping the Attitude pitch through MCP gives 7.052e-3 A
at 0 degrees, 4.988e-3 A at 45 (against `cos(45) = 0.7071`) and 1.312e-16 A at
90.

An earlier version of this file reported the fault chain as inert in the
browser. That was a real defect, since diagnosed and fixed: structural links
were recognised with `instanceof`, and the editor builds them from its own
inlined copy of core while the plugins use the global one, so the test was
false on a link that was correct in every other respect. Relations are now
recognised by their ontology id, and
`packages/tests/graph/structural-link-identity.test.ts` holds the line.
