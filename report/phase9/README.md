# Phase 9: shaft orientation

Phase 8 asked what happens when gravity goes away. Phase 9 asks what happens
when the machine is turned instead, with gravity left exactly where it was.

| File | What it is |
|---|---|
| `phase9-orientation.md` | The report: sweep, counter-example, control, consequence. |
| `images/phase9-tilt-sweep.svg` | Measured 1x current against tilt, with the cosine law. |
| `data/phase9-tilt-sweep.csv` | The sweep, for offline plotting. |

Generated by `packages/tests/privates/microg/rs385-tilt-report.test.ts`. The
physics itself is asserted separately in `rs385-tilt.test.ts`, so this
directory can be regenerated without re-deriving anything.

## Result in one line

The 1x current signature (once per shaft revolution) falls by twelve orders of
magnitude between a horizontal and a vertical shaft, in undiminished Earth
gravity, following `cos(tilt)` throughout. The vibration channel does not move.

## What was added to the codebase

Only an angle. `Rs385AtlasConfig.pitchDeg` and `AtlasConfig.pitchDeg`, wired to
`attitude.pitch` in the two atlas graphs. The projection
`g_body = R^T g_world` was already in `TransformNode._updateGravityCoupling`,
and both graphs already placed their assembly through
`Attitude -> Transform -> parentWorld`.
